设计语言

本页规定站点的设计取值与规则。修改样式或新增页面时，以本页为准。色板、字号和圆角从当前生效的样式表读取，不另抄数值。

定位

本站是供用户查找地址、确认包状态和浏览目录的索引站点。设计优先保证信息密度与数据可读性，再考虑留白和装饰。

Spectrum 2 文档的版式：左侧页面列表，中间正文，宽屏右侧列出本页小节。每页的小节可以直接跳转，页面增加时只需在侧栏加一行，顶栏不必改。本站不照搬 gentoozh.org 的卡片网格：卡片内边距会拉开数据表的行距。

色彩

中性色、状态色与阴影取自 Adobe 的 Spectrum 2 官方令牌 @adobe/spectrum-tokens 15.4.1，灰阶不带色相。强调色是 Gentoo 官方紫 #54487A（tyrian 主题 _variables.scss 与 Gentoo Wiki 的 Project:Artwork/Colors），悬停用官方的 #61538D。深色模式保留同一色相，只提高明度。全站只有这一个强调色相。

对比度按渲染出的颜色对计算：浅色强调色在白底上 8.1:1，深色强调色 #a897e3 在深色面板 #111111 上 7.4:1。强调色只用于链接、焦点环与代码里的值；当前项的竖条、标签页的指示条和选中的切换按钮都用中性灰，与 Spectrum 2 文档一致。状态色只出现在三处：已构建的对勾（绿）、注意提示框的竖条（橙）、复制失败的提示（红）。

字体

正文使用 Source Sans 3，它近似 Spectrum 的 Adobe Clean；代码与数据使用 Source Code Pro。包名、版本、路径、体积和时间需要纵向对齐，比例字体做不到。两个字体都只含拉丁字形并随站点自托管，中文落到系统的思源黑体、苹方或微软雅黑。

布局断点两档，按视口宽度；表格列另按正文栏宽度用容器查询收起，侧栏占去的宽度因此不必另算。新增断点前必须补上对应宽度的验证。

断点作用
64rem以下一栏：侧栏收进顶栏的菜单按钮，右侧本页目录改为顶栏正中的小节选择按钮，控件高度 40px；顶栏隐藏文字链接、GitHub 图标与分隔线，“文件”改列在侧栏的概览下方
34rem手机：状态行的数值换到标签下方，代码字号与内边距收紧，页面标题降到 40px
@container 58 / 48 / 40rem正文栏窄于这些宽度时依次隐藏体积列、版本列、日期列

媒体查询与容器查询都写在基准规则之后。同权重规则按源码顺序覆盖；写在基准规则之前会被后续基准规则覆盖。

规则原因
顶栏一行品牌名超长时以省略号截断，语言与主题始终可见
无脚本时侧栏在正文上方early.js 在 <html> 写入 data-js 后，侧栏才收进菜单按钮；脚本关闭时导航仍然可用
表格逐列隐藏依次隐藏体积列与版本列，状态列保留到最后
表头留在视口内thead 使用 position: sticky，top 使用 --nav-h。顶栏同样为 sticky；若 top 为 0，表头会被顶栏遮挡。util.js 测量窄屏顶栏高度并写入变量
包名在斜线处断行用 <wbr> 标出断点。word-break: break-all 会把 app-admin/1password 切成无法辨认的三段
页面不横向滚动代码块与地址栏在各自容器内滚动，表格通过逐列隐藏适配视口。表格外层不得设置 overflow；overflow-x 不是 visible 时，overflow-y 的 visible 会计算为 auto，sticky 表头将绑定到该容器
正文内边距手机 16px，桌面 40px。更小的值会让正文紧贴视口边缘

修改后逐一验证 320 至 1280 的每个宽度：可见列、指纹换行、标题字号、顶栏折行、表头吸顶、documentElement.scrollWidth 不大于 clientWidth。使用指定宽度的 iframe 测量；修改 html.style.width 不会触发媒体查询。

组件

外壳

顶栏、侧栏、页脚与右侧目录由 site/tools/render-chrome.py 从 site/tools/chrome/ 的模板生成，各页一致。顶栏左侧是站点标志与站名，正中是搜索按钮，右侧依次是“文件”图标按钮（S2 Folder 图标）、GitHub 图标、分隔线、语言与主题按钮，顺序与 React Spectrum 文档的顶栏相同。侧栏顶端是单独的概览，其下每个产品一个折叠分组：组名与页面行同样大小、字重与颜色，行尾的 Chevron 在展开时用 150ms 转向下方，组内页面再缩进 16px，展开与收起时立即出现或消失。悬停一行时左侧立即出现浅灰竖条，Chevron 加深；按下时整行按 S2 pressScale 下沉；键盘焦点环画在行内 2px，圆角 8px。以上状态均于 2026-09-29 在官方文档侧栏实测。没有脚本时各组全部展开；有脚本时展开当前页所在的组，其余组沿用读者在本次会话中的选择，初始按 data-default-open。新增页面只需在 nav.html 的组里加一行。以 / 结尾的行是文件浏览器的目录（如 /gigos/），不进上一页与下一页；浏览该目录时，侧栏把当前页标记从“文件”移到这一行。当前页加粗，左侧一道中性灰竖条；右侧目录由 docs.js 从正文 h2 生成，读到的小节同样标出竖条；小节只列在这里，不进侧栏，与 React Spectrum 文档一致。1024px 以下右侧目录收起，顶栏正中改为小节选择按钮：按钮写出正在读的小节，第一个小节之前写页面标题，点开是列出标题与各小节的弹出菜单。页面滚动 24 到 64px 之间，按钮上移淡入，顶栏浮起并加阴影；减少动态效果时按钮直接显示。只有正文含两个以上 h2 的页面保留右侧目录一栏，其余页面的正文在面板内居中。面板高一个视口，粘在顶栏下方：页面滚动时正文从顶栏下方经过，面板上方的圆角始终可见。官方文档在 1024px 以上让面板自身滚动、页面不滚动（2026-09-29 实测）；这里保留页面滚动，锚点、目录的阅读位置与键盘滚动不受影响。

选项切换

频道

切换整块内容的选择（配置方式）画成 Spectrum 的标签页：文字下方一道 2px 中性灰横条，没有底线。频道、镜像与包列表筛选是 Spectrum 2 的分段控件：灰色轨道，选中项加 2px 描边；镜像选择与它改动的地址或代码放在同一个安装框里。文件浏览器在根目录以下用同一组镜像选择器改写文件的下载链接，默认源站；目录列表仍从源站读取。所有镜像选择器共用 mirror-source，在一页选定后其他页沿用。当前项写在元素上（.on 与 aria-pressed），切换后立即更新相关地址、配置和状态。标签页切换的面板带 data-pane；初始项是标记中带 .on 的标签，链接指向某个面板内的锚点时先切到该面板，右侧目录只列出可见面板的小节。没有脚本时标签隐藏，各面板依次显示。

菜单按钮

语言与主题各是一个安静的 ActionButton：32px 高、圆角 10、20px 图标，语言按钮只有地球图标，名称写出当前语言（如“语言：简体中文”），不加工具提示，与 S2 ActionButton 文档一致。语言按钮点开是 S2 Menu：弹出层内距 8px、圆角 10、带阴影，深色下另加 1px gray-200 描边；菜单项高 32px，已选项只在起始侧显示勾号，悬停与键盘焦点为 gray-200 底、gray-900 字。键盘按 WAI-ARIA 菜单按钮实现：Enter、空格或下箭头展开并聚焦已选项，上下箭头、Home、End 移动，Enter 选择，Escape 收起并把焦点还给按钮，Tab 或点击外部也会收起。

主题默认跟随系统。主题按钮与 React Spectrum 文档相同，是切换按钮而不是菜单：跟随系统时按下改用与当前相反的主题，再按一次恢复跟随系统。图标是按下后将切换到的主题：浅色生效时为 Contrast，深色生效时为 Lighten。按钮名称写出当前模式与按下的效果，例如“主题：跟随系统（浅色），按下改用深色”。选定的主题保存在 mirror-theme，恢复跟随系统时清除；early.js 在绘制前写入 data-theme，CSS 按 data-theme 与系统设置选择图标，因此首帧即正确，系统设置改变时也随之更新。不执行脚本时两个按钮隐藏，主题跟随系统；语言链接放在 <details> 里，但译文由脚本替换，没有脚本时页面仍是简体。

站内搜索

站内搜索照 React Spectrum 文档的搜索实现（doona 文档照它复制，见 doona-docs 的 site/scripts/search.js 与 site/styles/search.css）。顶栏中间是 S2 SearchField 形状的触发按钮：40px 高、全圆角、2px 浅灰边框（悬停时加深，获得焦点时为正文色），末端是 24px 高的快捷键标签；点按、在按钮上直接输入（字符进入搜索框）、Ctrl K（Mac 为 Command K）或 / 打开几乎占满窗口的模态对话框，关闭按钮在右上角。左栏是站点标志、站名与一句介绍，右侧依次是 2px 深色边框的搜索框、分类标签和结果。分类标签按侧栏的产品分组生成，外加“全部”与“包”，以竖线与最后的外部链接标签（Gentoo 中文社区，带 LinkOut 图标）分开；选中的标签以正文色填充、底色文字，其余为浅灰底。页面结果是 S2 Card 形状的卡片，四列：圆角 10、带阴影，上方柔和的紫色渐变底板居中放分组的 64px 白色图标，下方是粗体标题与至多两行说明；当前结果加 2px 正文色边框。包结果是 32px 高的紧凑列表行，结果在对话框内滚动。1024px 以下触发按钮只显示图标，对话框占满屏幕，站名移到顶部。

搜索框是 combobox，结果是 listbox：焦点始终在搜索框，方向键、Home、End 通过 aria-activedescendant 移动当前结果，当前结果带焦点环，Enter 打开；输入后自动选中第一项。Esc 与关闭按钮关闭对话框，焦点回到触发按钮；Tab 在对话框内循环。索引由 site/tools/build-search-index.py 从页面生成，--check 在索引过期时失败，首次打开时加载；包数据取自 /packages.json，查询达到 2 个字符才匹配。打开与关闭通过 View Transition 在触发按钮与对话框之间变形，历时 250ms；手机上整页淡入淡出；减少动态效果时不做动画。

图标

图标全部是 Spectrum 2 workflow 图标，逐个取自 @react-spectrum/s2 1.7.1 的 icons/，几何不改，颜色取 currentColor：MenuHamburger、GlobeGrid、Lighten、Contrast、DeviceDesktop、Copy、Search、ChevronRight、OpenIn、Checkmark、Close。与 14px 文字并排时 20px，在面包屑、外部链接与菜单勾号处 16px。GitHub 标志沿用 GitHub 自己的图形，React Spectrum 文档也这样做。

动效

动效照 React Spectrum 文档实测：切换主题时底色立即切换，控件颜色以 150ms 过渡，主题按钮的图标以 200ms 交叉淡入淡出并旋转 90 度；菜单以 200ms 淡入，同时从按钮方向位移 4px，关闭时原路退出，打开用 CSS 默认的 ease 曲线，关闭用 S2 的 in 曲线（Popover.tsx）；按下按钮时下沉 2px，与 S2 pressScale 相同；手机上的页面列表以 250ms 淡入。焦点环立即出现，换页与内容加载都没有动画，滚动只驱动 1024px 以下顶栏的小节选择按钮。

令牌在 tokens.css：缓动曲线 --animation-ease-in-out、--animation-ease-in、--animation-ease-out 取自 @spectrum-css/tokens 16.0.2，与 S2 样式宏相同；时长 --animation-duration-state（150ms）与 --animation-duration-overlay（200ms）取 S2 组件实际使用的值，--animation-duration-500（250ms）取自同一份令牌。所有动效只写在 prefers-reduced-motion: no-preference 里，系统要求减少动态效果时状态立即切换。首次绘制不播放过渡：early.js 在绘制前设定主题，并用 data-settling 在页面脚本恢复所存选项期间停用过渡。

[gentoo-zh]
sync-uri = https://distfiles.gentoozh.org/binpkgs/x86-64
priority = 10
verify-signature = true

代码块照 React Spectrum 文档的写法：gray-50 底、圆角 16、内距 32（1024px 以下 12），没有标题栏，代码 14/21（1024px 以下 12/18）。配置片段的第一行是注释，写出要编辑的文件，与文档在代码第一行注明 src/app.tsx 的方式相同。复制按钮与 sudo 开关在右上角：复制是 24px 的安静按钮，只有 Copy 图标，名称写在 aria-label；sudo 是 24px 的切换按钮，打开时以正文色为底。复制内容等于屏幕上显示的文字，不含提示符。

语法颜色在生成页面时由 site/tools/highlight.py 写入，页面不依赖脚本；颜色过期时 render-chrome.py --check 报错。颜色按文档高亮器的角色取值（s2-docs Code.tsx）：字符串 green-1000，关键字 magenta-1000，数字 pink-1000，属性 indigo-1000，命令与节名 red-1000，变量 fuchsia-1000，注释与提示符 gray-700，标点保持正文色。脚本改写的镜像地址与 sudo 前缀各是一个完整元素，改写后保留所在位置的颜色。

超长的命令按 shell 续行符拆成多行；无法拆开的长值（GENTOO_MIRRORS）在块内折行，复制内容不变。其余超宽的行在代码块内横向滚动，页面本身不横向滚动。滚动条用细样式，滑块取 --border-strong。

sudo mkdir -p /etc/portage/binrepos.conf
sudo tee /etc/portage/binrepos.conf/gentoo-zh.conf > /dev/null <<'EOF'
[gentoo-zh]
sync-uri = https://distfiles.gentoozh.org/binpkgs/x86-64
priority = 10
EOF
sudo emerge --ask --getbinpkg <package>

单行命令用文档的 Command 样式：S2 Prompt 图标、等宽命令，复制按钮紧跟在命令后面，是 24px 的 gray-100 按钮；sudo 开关在行尾。安装框是文档的 InstallCommand：分段控件距边 24px（1024px 以下 12px），下方是它改动的命令、地址或代码块，这些内容不再单独铺底。

链接

链接的颜色按 S2 Link：强调色，悬停时换成下一级强调色；页脚链接为 gray-800，悬停变 gray-900。与 S2 不同，全站链接不加下划线，平时和悬停时都没有（维护者 2026-09-29 的要求）；键盘聚焦时显示站内统一的焦点环。访问过的链接不另设颜色。上一页与下一页按 S2 Card 的 tertiary 变体：无底色，2px gray-100 描边，悬停与键盘聚焦时变 gray-200，按下时按 pressScale 下沉；官方文档目前已不在页尾放上一页与下一页。

语言

简体是源文案，直接写在 HTML 中；i18n.js 在 body 末尾替换繁体与英文。浏览器可能在替换前开始绘制，因此 early.js 位于 <head>，同步判断访客语言。简体立即显示；其他语言在替换完成前隐藏正文，并以 1.5 秒为最长等待时间。

标记换什么
data-i18n元素的文字
data-i18n-html整段内容，含里面的标签与链接
data-i18n-href链接地址。gentoozh.org 按语言分路径
data-langblock每种语言各写一份，只显示当前语言的内容

顶栏、侧栏与页脚由全站共用，并随当前语言切换。每个页面的顶栏都有语言菜单，用户可以修改全站语言偏好。

文字

先写结论，再说明必要理由；需要因果关系时明确写出。每段不超过 4 句，不添加重复总结。简体使用大陆用语（软件、网络、程序、数据、默认、内存），繁体使用台湾用语，技术术语保留英文原文。

Portage 接受 binpkg 时不比较 CFLAGS，因此构建端必须保证该参数。

我们非常重视兼容性，会尽力确保您的使用体验。
