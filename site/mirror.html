用镜像

二进制包与 distfiles 分开配置，可以来自不同的镜像。 下面以本站的二进制包配南京大学的 distfiles 为例。

/etc/portage/binrepos.conf/gentoo-zh.conf 
sync-uri = https://mirrors.gentoozh.org/binpkgs/x86-64
/etc/portage/make.conf 
GENTOO_MIRRORS="${GENTOO_MIRRORS} https://mirror.nju.edu.cn/gentoo-zh"

自己开镜像

rsync 公开开放，无需申请。一个模块里就是 binpkgs/ 与 distfiles/。同步到本地后用 HTTP 提供即构成一个完整的镜像， 因为索引中的 PATH 是相对路径，不依赖主机名。

rsync 
$ rsync -a --delete --delay-updates rsync://mirrors.gentoozh.org/gentoo-zh/ /srv/mirror/gentoo-zh/

每日同步一次。因为包名含版本与 build id，内容不再变化，所以已有的文件不会重复传输。 --delay-updates 让这一批文件在末尾一次换入。不加则索引可能先落地， 而它引用的包尚未传完，这段时间下游返回 404。
