Gentoo-zh 下载

中国大陆与海外镜像提供 gentoo-zh overlay 及其 distfiles、binary package 与 Live ISO。

添加 gentoo-zh overlay 
sudo emerge --ask app-eselect/eselect-repository
sudo eselect repository add gentoo-zh git https://mirrors.cernet.edu.cn/gentoo-zh.git
sudo emaint sync -r gentoo-zh

开始使用

  • Overlay添加 gentoo-zh overlay，安装 fcitx 输入法、中文字体与中国大陆常用应用。
  • distfiles让 Portage 从本站镜像下载 overlay 软件包的源码。
  • binhost安装已签名的 binary package，省去本地编译，分 stable 与 unstable 两个频道。
  • Live ISO下载每周更新的 CJK 最小安装镜像，另可下载独立项目 Gig-OS 的镜像。
  • 镜像查看中国大陆与海外的镜像及同步地址。
  • 帮助选择频道、配置 binary package 与 overlay 的常见问题。
