配置

gentoo-zh overlay 的二进制包与 distfiles 镜像。两者相互独立，按需分别配置。 ::gentoo 的部分用 社区镜像列表里的节点。

Distfiles

这里只有 overlay 的源码，不能替代官方源，因此是追加而非替换。 地址不写 distfiles/，portage 会自己补上。 这里把镜像都列出：GENTOO_MIRRORS 是按顺序尝试的列表， 选中的取不到时会落到后面的地址。

优先
/etc/portage/make.conf 
GENTOO_MIRRORS="${GENTOO_MIRRORS} https://mirrors.cernet.edu.cn/gentoo-zh https://distfiles.gentoozh.org"
shell 
tee -a /etc/portage/make.conf > /dev/null <<'EOF'
GENTOO_MIRRORS="${GENTOO_MIRRORS} https://mirrors.cernet.edu.cn/gentoo-zh https://distfiles.gentoozh.org"
EOF

因版权等原因不希望某个包被镜像时，在其 ebuild 中加入 RESTRICT="mirror"，同步工具会跳过。

二进制包

镜像
sync-uri https://mirrors.cernet.edu.cn/gentoo-zh/binpkgs/x86-64

这一段把三步一次做完。想知道每一步在做什么，切到手动配置。

shell 
emerge sec-keys/openpgp-keys-gentoozh
getuto
gpg --homedir /etc/portage/gnupg --import /usr/share/openpgp-keys/gentoozh.asc
gpg --homedir /etc/portage/gnupg --batch --yes --pinentry-mode loopback \
    --passphrase-file /etc/portage/gnupg/pass --lsign-key 6A0726AF1476A2F382C6AC6638A0234EC16AD42E
gpg --homedir /etc/portage/gnupg --check-trustdb

mkdir -p /etc/portage/binrepos.conf
tee /etc/portage/binrepos.conf/gentoo-zh.conf > /dev/null <<'EOF'
[gentoo-zh]
sync-uri = https://mirrors.cernet.edu.cn/gentoo-zh/binpkgs/x86-64
priority = 10
verify-signature = true
location = /var/cache/binhost/gentoo-zh
EOF

tee -a /etc/portage/make.conf > /dev/null <<'EOF'
FEATURES="${FEATURES} getbinpkg"
EOF

1导入签名公钥 6A07 26AF 1476 A2F3 82C6 AC66 38A0 234E C16A D42E

shell 
emerge sec-keys/openpgp-keys-gentoozh
getuto
gpg --homedir /etc/portage/gnupg --import /usr/share/openpgp-keys/gentoozh.asc
gpg --homedir /etc/portage/gnupg --batch --yes --pinentry-mode loopback \
    --passphrase-file /etc/portage/gnupg/pass --lsign-key 6A0726AF1476A2F382C6AC6638A0234EC16AD42E
gpg --homedir /etc/portage/gnupg --check-trustdb

不想装这个包，也可以直接下载公钥文件，见 FAQ。

getuto 建立 /etc/portage/gnupg。没有它，上面三条 gpg 命令会以 no writable keyring found 失败——gpg 不会自己建这个目录， 而 portage 只在第一次取二进制包时才会调用它，那已经是第 2、3 步之后了。 签名用的是 getuto 建立的 Portage Local Trust Key，口令在 /etc/portage/gnupg/pass，因此要用 --passphrase-file 读。 验签以 portage 用户执行，该用户对 trustdb 没有写入权限， 所以 trustdb 要预先算好。

2添加仓库

镜像
/etc/portage/binrepos.conf/gentoo-zh.conf 
[gentoo-zh]
sync-uri = https://mirrors.cernet.edu.cn/gentoo-zh/binpkgs/x86-64
priority = 10
verify-signature = true
location = /var/cache/binhost/gentoo-zh

默认是南京大学，中国大陆下载会更快；源站在美国，部分地区下载可能较为缓慢。 两边的包都是一样的，签名也是同一份，更换哪个都不会影响验签。

3打开 getbinpkg（追加）

/etc/portage/make.conf 
FEATURES="${FEATURES} getbinpkg"

验签由第 2 步的 verify-signature = true 提供，只作用于本源。 FEATURES=binpkg-request-signature 是全局的，会覆盖它，也会要求你自己 用 FEATURES=buildpkg 编出来的包带签名——那些包默认没有签名，于是每个 本地构建都会在合并时报 GnuPG verification failed。要开它就得同时配好 binpkg-signing 与本机签名密钥。
