# Site fonts

Source Sans 3 stands in for Spectrum's Adobe Clean; Source Code Pro is the code face of the
React Spectrum documentation. Both files are the official Google Fonts Latin WOFF2 subsets,
unmodified, as retrieved for doona-docs on 2026-09-28 from the Google Fonts CSS API. Chinese
text falls back to Noto Sans CJK or the system sans-serif font.
